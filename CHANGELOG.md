# Changelog

## 0.1.0

Initial package candidate.

- Core utilities cover async queues, lifecycle, cancellation, timeouts, disposal, events, observables, state, caching, memoization, rate limiting, and typed SDK errors.
- Numeric utilities include finite-number, safe-integer, and tolerance validation, approximate equality, clamping, and degree–radian conversion.
- ESM entry points and TypeScript declarations are available at `lean-math-sdk`, `lean-math-sdk/core`, and `lean-math-sdk/numeric`. The package has no runtime dependencies.
